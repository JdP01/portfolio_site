Definitions used throughout this guide

Glossary

155 of 155 terms

Acceptance criteria
Observable, testable conditions for accepting a particular work item; for example a documented recall target within a stated review budget on a specified evaluation set.
Accuracy
Fraction of all predictions that are correct: (TP + TN) / N. Can be misleading when classes are imbalanced.
Activation function
Nonlinear transformation of a neural network layer, such as ReLU. Without nonlinearities, stacked affine layers still represent an affine function.
Adam
Adaptive gradient optimizer maintaining exponential moving averages of gradients and squared gradients. It still requires a suitable learning rate and validation.
Agile
Iterative delivery with feedback, small prioritized work items, and adaptation; not a substitute for reproducibility or required approvals.
Anomaly detection
Identifying observations that deviate from an expected reference pattern. Unusual does not automatically mean defective or fraudulent.
AUC
Area under a specified curve. ROC-AUC measures positive-versus-negative ranking; PR-AUC summarizes precision–recall behavior and depends on prevalence.
Audit trail
Traceable record of relevant access, decisions, approvals, versions, and changes. Audit logs should avoid storing unnecessary sensitive payloads.
Autoencoder
Neural network trained to reconstruct its input through an encoded representation. Reconstruction error can be an anomaly score, not a calibrated probability.
Backpropagation
Applying the chain rule backward through a network to compute parameter gradients; an optimizer then uses those gradients to update weights.
Bag of words
Text representation using token counts or weights while discarding global word order. N-gram features can retain limited local order.
Bagging
Training models on bootstrap samples and aggregating their predictions to reduce variance, especially when their errors are not perfectly correlated.
Base rate / prevalence
Fraction of the target population belonging to a class before considering additional evidence. Production precision depends strongly on this fraction.
Baseline
A simple reference approach against which a more complex solution is compared using the same evaluation protocol and business criteria.
Bayes’ theorem
Posterior = likelihood × prior / evidence: P(C|E) = P(E|C)P(C)/P(E), provided P(E) > 0.
Bias
Systematic prediction error from modeling assumptions or limited flexibility. Distinct from social or measurement bias, although both can matter.
Bias–variance tradeoff
For squared-error prediction, expected error can be decomposed into squared bias, variance, and irreducible noise under standard assumptions.
BIO tagging
Token labels marking the Beginning, Inside, or Outside of an entity span; for example B-PERSON, I-PERSON, O.
BIO tagging
Entity-labeling scheme in which B marks the first token of an entity, I a subsequent token, and O a token outside an entity.
Boosting
Sequential ensemble learning in which new learners address weaknesses in the current ensemble; gradient boosting fits negative loss gradients.
Calibration
Agreement between predicted probabilities and observed event frequencies. Among cases scored near 0.8, roughly 80% should be positive in a calibrated model.
Causality
Whether intervening on one variable changes another outcome. Predictive association alone does not establish a causal effect.
Centroid
Arithmetic mean feature vector of a group of observations; the representative center in ordinary k-means clustering.
Change control
Documented review, testing, approval, release, and rollback procedures for managing changes and their risks.
CI/CD
Continuous integration automates checks on changes; continuous delivery prepares approved releases, while continuous deployment automatically releases passing changes.
Classification
Predicting a discrete class label. Class-probability estimation produces probabilities that can be converted into decisions using a threshold.
Clustering
Grouping observations by a similarity criterion without a supplied target label. A cluster is not automatically a meaningful business segment.
Concept drift
Change over time in the relationship P(Y|X) between inputs and outcomes, potentially degrading a deployed model.
Conditional independence
Two variables provide no additional information about one another once a conditioning variable is known; the core simplifying assumption of Naive Bayes.
Confidence interval
An interval procedure with a stated long-run coverage rate under its assumptions. A realized frequentist 95% interval does not assign 95% probability to a fixed parameter.
Confounding
A shared cause of a putative treatment and outcome that can create a misleading association between them.
Confusion matrix
Counts of predicted versus actual classes. State which class is positive and the row/column orientation before interpreting it.
Container
An isolated running process environment created from an image; containers typically share the host operating-system kernel.
Container image
Versioned filesystem and runtime metadata used to create containers. An image is an artifact; a container is a running or stopped instance of it.
Continuous integration
Automatically building or checking integrated code changes with tests, linting, and other quality gates before they are accepted.
Convexity
A property of a feasible set and objective that, for convex minimization, makes any local minimum a global minimum. It does not necessarily make the minimizer unique.
Corpus
Collection of documents used for text analysis, training, or retrieval.
Cosine distance
One minus cosine similarity: 1 − (x·y)/(‖x‖‖y‖). Requires a convention for zero vectors and ignores vector magnitude.
Counterfactual
The outcome that would have occurred under a different action or treatment. Only one potential outcome is observed for a given unit at a time.
CRISP-DM
Cross-Industry Standard Process for Data Mining: business understanding, data understanding, data preparation, modeling, evaluation, and deployment; an iterative lifecycle.
Cross-validation
Repeated train/validation partitions used to estimate performance or select settings. Splitting must respect dependencies such as patients, machines, and time.
Cumulative response
Recall achieved by targeting the top fraction of a ranked population. Also called a cumulative gains curve.
Data drift
Change in the distribution of inputs, often written P(X). It is a warning signal, not proof of performance degradation.
Data leakage
Information entering model development that would not legitimately be available at prediction time or in an independent evaluation. See also leakage.
Data reduction
Replacing a dataset with a smaller representation that preserves useful structure while accepting some information loss.
Data science
Principles and methods for extracting useful knowledge from data and connecting that knowledge to decisions.
Decision stump
A decision tree with one split, useful as a simple interpretable baseline.
Decision threshold
Cutoff converting a score into an action or class. Choose using validation, business costs, capacity, and acceptable risk rather than defaulting to 0.5.
Definition of done
Agreed completion criteria covering implementation, tests, review, documentation, approvals, and handoff as applicable.
Dendrogram
Tree diagram of hierarchical cluster merges. Its heights reflect merge dissimilarities according to the chosen linkage.
Deployment
Putting an analysis or model into a real workflow with ownership, monitoring, support, and a path to rollback.
Dimensionality
Number of input features or representation coordinates. Many weak dimensions can make distance-based methods noisy and expensive.
Distribution shift
A mismatch between development and deployment distributions. Examples include new machines, changed prevalence, different document templates, or concept drift.
Docker
Tooling for building images and running containers. This reference site requires none of it.
Drift
Change in data distributions or input–outcome relationships after development. Monitoring must distinguish input drift from concept drift.
Embedding
A learned numeric representation of an object, such as a token or document, intended to capture useful structure.
Ensemble
Combination of multiple models. Benefits depend on model quality, error diversity, and an appropriate aggregation strategy.
Entropy
Uncertainty of a discrete distribution: H = −Σ pᵢ log₂(pᵢ), with 0 log₂ 0 treated as 0. Binary entropy is maximal at equal class probabilities.
Euclidean distance / L2 distance
Straight-line distance between vectors: √Σ(xⱼ − zⱼ)². Feature units and scaling strongly affect it.
Expected value
Probability-weighted average of possible outcomes: Σ P(outcome) × value(outcome). Enables cost-sensitive decisions.
F1 score
Harmonic mean of precision and recall: 2TP/(2TP + FP + FN). Ignores true negatives and does not directly represent business cost.
False negative
An actual positive predicted negative; for example, a sensitive entity missed by a detector.
False positive
An actual negative predicted positive; for example, a normal machine event incorrectly flagged for inspection.
Feature
Input attribute used by a model. A feature vector is the ordered representation of one observation.
Feature scaling
Transforming feature magnitudes, for example by training-set means and standard deviations. Essential for many distance- and gradient-based methods.
Feature selection
Choosing a subset of input variables. Data-driven selection must occur inside training folds to avoid leakage.
Fit versus transform
Fit learns preprocessing state from training data, such as means or vocabulary. Transform applies that already-learned state to data without relearning it.
Forward pass
Computing layer outputs from inputs through a network to obtain a prediction or reconstruction before calculating loss.
Gaussian mixture model (GMM)
Probabilistic model representing data as a mixture of Gaussian distributions, producing soft component-membership probabilities.
Generalization
A model’s ability to perform on new observations from the intended deployment setting, not just on its training examples.
Git
Distributed version-control system tracking changes and supporting branches, review, and reproducible source history. Do not commit secrets or restricted data.
Gradient
Vector of partial derivatives indicating the direction of steepest local increase of a differentiable function.
Gradient descent
Iterative minimization using θ ← θ − η∇L(θ). Learning rate η controls update size; convergence depends on the objective and settings.
Hinge loss
For y ∈ {−1,+1}, max(0, 1 − y·score). Penalizes incorrectly classified points AND correctly classified points inside the unit margin.
Hyperparameter
Setting selected outside ordinary parameter fitting, such as tree depth, regularization strength, or number of neighbors.
Hypothesis testing
Assessing how incompatible observed data are with a specified null model. A p-value is not the probability that the null is true.
Induction
Learning general patterns from observed training examples to apply to previously unseen examples.
Information gain
Parent entropy minus the child entropies weighted by their relative sample counts. Measures class-uncertainty reduction after a split.
Inverse document frequency (IDF)
A weight decreasing with document frequency. Unsmoothed log(N/df) is zero for a term in every document; smoothed conventions may instead give 1.
Jaccard distance
For sets A and B, 1 − |A ∩ B|/|A ∪ B|. Useful for binary presence data when shared absences should not count as similarity.
K-means
Clustering by iterating nearest-centroid assignment and centroid recomputation to reduce within-cluster squared Euclidean distance. Sensitive to scale, initialization, and outliers.
K-nearest neighbors (kNN)
Predicting from the targets of nearby training observations: voting for classification or averaging for regression. The neighbor count k is a complexity setting.
KKT conditions
Karush–Kuhn–Tucker conditions combine stationarity, primal feasibility, dual feasibility, and complementary slackness. Under suitable convexity and constraint qualifications, they characterize a global optimum.
Kubernetes
Platform for orchestrating containerized workloads, including scheduling, desired replica state, rollout, and service discovery.
L1 norm / penalty
Sum of absolute values. As a regularization penalty, it can drive some fitted coefficients exactly to zero.
L2 norm / penalty
Euclidean norm is √Σwⱼ². The usual ridge penalty uses the squared L2 norm, Σwⱼ², rather than the norm itself.
Laplace smoothing
Adding pseudo-counts to avoid extreme estimates from sparse data. A binary leaf with n positives and m negatives gives (n+1)/(n+m+2).
Lasso
Linear regression with an L1 coefficient penalty. Can select features, but correlated predictors can make the selected subset unstable.
Latent Dirichlet allocation (LDA)
Probabilistic topic model treating documents as mixtures of topics and topics as distributions over words. Distinct from linear discriminant analysis.
Latent information
Unobserved structure inferred from data, such as factors behind movie ratings or topics behind documents. Not necessarily a causal explanation.
Latent semantic indexing (LSI)
Low-rank text representation commonly obtained by truncated singular value decomposition of a term–document matrix.
Leakage
Using future, target-derived, duplicated, or evaluation-set information in training or selection, producing misleadingly optimistic results.
Learning curve
Training and validation performance plotted against training-set size. Different from a fitting curve plotted against model complexity.
Least privilege
Granting people and services only the data access and permissions necessary for their approved tasks, with review and removal when no longer needed.
Leverage
For an association rule A → B: P(A ∩ B) − P(A)P(B), the absolute excess joint frequency over independence.
Lift
Association lift is P(B|A)/P(B). Ranking lift at fraction q is cumulative recall(q)/q. Both compare against a baseline, but they measure different objects.
Likelihood
Probability of observed evidence as a function of a proposed model or class. In Bayes’ theorem, P(E|C) is the evidence likelihood under class C.
Linear programming (LP)
Optimization of a linear objective subject to linear constraints with continuous decision variables. Integer restrictions change it into an integer or mixed-integer program.
Link prediction
Estimating whether a relationship exists or will appear between entities, often in a graph. Temporal edges and negatives need careful construction.
Linkage
Rule for measuring dissimilarity between clusters in hierarchical clustering, such as single, complete, average, or Ward linkage.
Log loss
Binary probability loss −[y ln(p) + (1−y) ln(1−p)]. Confident wrong predictions are heavily penalized.
Log odds
ln[p/(1−p)], ranging over all real numbers for 0 < p < 1. Logistic regression models log odds as a linear function of inputs.
Logistic regression
A classification probability model p = 1/(1 + exp(−wᵀx − b)). A linear boundary in input space does not imply perfect separability.
Loss function
Numerical penalty for a prediction error. Training minimizes a loss, often with a regularization penalty; evaluation metrics can differ.
Margin
Separation between a decision boundary and observations, usually normalized by weight magnitude for geometric distance. SVMs trade large margins against violations.
Mean absolute error (MAE)
Average |y − prediction| in target units. Less sensitive to very large residuals than squared-error metrics.
Mean squared error (MSE)
Average squared prediction residual, measured in squared target units. Gives large residuals greater weight.
Mixed-integer linear programming (MILP)
Linear objective and constraints with some integer-valued variables, used for indivisible quantities and on/off scheduling decisions.
Mixed-integer programming
Optimization with both integer and continuous decision variables. When the objective and constraints are linear, the problem is a MILP.
Model card
Document describing intended use, training and evaluation data, performance, limitations, risks, and ownership of a model.
N-gram
Sequence of n adjacent tokens or characters. Bigrams for “the quick fox” are “the quick” and “quick fox”.
Naive Bayes
Classifier combining class priors with feature likelihoods under conditional feature independence given the class. Often a useful text baseline.
Named entity recognition (NER)
Detecting typed spans in text, such as person names or organizations. Entity identification and entity normalization are separate tasks.
Nested cross-validation
Inner folds select hyperparameters; outer held-out folds estimate performance of the entire selection procedure.
Objective function
Quantity an optimizer minimizes or maximizes. In decision optimization it encodes business cost or value; in training it commonly includes loss and regularization.
Odds
For event probability p, odds are p/(1−p). Probability 0.9 gives odds 9, not odds 0.9.
Optimality gap
Difference between the objective of a known feasible solution and a valid bound on the best possible objective; solvers may report an absolute or relative gap.
Overfitting
Fitting idiosyncrasies or noise in training data so that performance on genuinely new cases suffers.
Parameter
Value learned during model fitting, such as a regression coefficient or network weight. Distinct from a hyperparameter chosen through model selection.
Personally identifiable information (PII)
Information that identifies a person directly or when linked with other information. The exact legal and policy definition depends on the governing context.
Personally identifiable information (PII)
Information that can identify an individual directly or through linkage. Exact definitions and required controls depend on applicable law and organizational policy.
Pipeline
Ordered preprocessing and modeling steps fitted consistently on training data and reused at inference. Fitting inside CV folds prevents preprocessing leakage.
Posterior probability
Probability after incorporating observed evidence, proportional to the prior multiplied by the evidence likelihood.
PR-AUC
Area under a precision–recall curve; sensitive to prevalence. Average precision is a related summary with a particular stepwise integration convention.
Precision
TP/(TP + FP): among predicted positives, the fraction actually positive. Undefined when there are no positive predictions unless a reporting convention is stated.
Principal component analysis (PCA)
Linear projection onto orthogonal directions of greatest training-data variance. Sensitive to feature scaling; high variance need not imply predictive relevance.
Prior probability
Probability before observing the evidence under consideration; in classification, often the class prevalence.
Profiling (behavior description)
Characterizing typical behavior of an individual or population to establish a reference for analysis or anomaly detection. Distinct from runtime performance profiling.
Protected health information (PHI)
Under HIPAA, individually identifiable health information held or transmitted by covered entities or business associates, subject to the applicable definitions and exceptions. Context matters.
Protected health information (PHI)
Individually identifiable health information in the applicable HIPAA covered-entity or business-associate context, subject to the rule’s definitions and exceptions. Not every health-related word is PHI.
Pruning
Removing splits or branches from a fitted tree to control complexity, using a defined selection criterion rather than repeated final-test feedback.
Random forest
Ensemble of trees using bootstrap sampling and random feature subsets to reduce correlation between trees and improve generalization.
Recall / sensitivity / TPR
TP/(TP + FN): fraction of actual positives found by the model. Distinct from precision.
Reconstruction error
Difference between an input and an autoencoder’s reconstruction, aggregated using an explicit metric such as mean squared error.
Regression
Predicting a numeric target such as demand, cost, or cycle time. Logistic regression is named historically but is generally used for classification.
Regularization
Constraining model complexity through penalties or other controls to improve generalization. Strength should be selected using appropriate validation.
Reproducibility
Ability to trace and repeat an experiment using recorded code, data versions, configuration, environment, and evaluation protocol. Seeds alone do not guarantee it.
Ridge regression
Linear regression with a squared L2 coefficient penalty. Shrinks coefficients toward zero without usually making them exactly zero.
ROC curve
Plot of true-positive rate versus false-positive rate as a decision threshold varies. A low FPR can still mean many alerts when negatives are numerous.
Root mean squared error (RMSE)
Square root of MSE, expressed in original target units while retaining strong sensitivity to large errors.
Scrum
An agile framework using accountabilities, a prioritized backlog, timeboxed sprints, and inspection/adaptation events. Team practices vary.
Sigmoid
Function σ(z) = 1/(1 + e^(−z)), mapping real-valued scores to the open interval (0,1).
Silhouette score
For a point, (b−a)/max(a,b), comparing mean within-cluster distance a with the nearest alternative cluster distance b. A geometric diagnostic, not business validation.
Soft clustering
Assigning membership weights or probabilities across clusters rather than one hard assignment per observation.
Sparse representation
A representation where most entries are zero; specialized storage avoids materializing every zero, useful for large text vocabularies.
Stratification
Constructing splits to approximately preserve class proportions. Does not prevent leakage across repeated entities or time.
Support
Frequency of an itemset: P(A ∩ B) for a pair of co-occurring items. Different from the support vectors of an SVM.
Support vector machine (SVM)
Margin-based model with a tradeoff between margin size and loss for violations. Kernels can produce nonlinear boundaries; raw scores are not automatically probabilities.
Target variable
Outcome to predict, defined with a unit of observation, prediction timestamp, outcome horizon, and label-availability rule.
TF–IDF
Term-frequency weight multiplied by inverse document frequency. Vocabulary and IDF statistics must be fitted on training data only.
Tokenization
Splitting text into units such as words, subwords, or characters. Span detectors must preserve mappings to original character offsets.
Training–serving skew
Mismatch between how inputs or predictions are produced during training and production, such as different encodings, feature timestamps, or preprocessing versions.
Underfitting
A model or representation too limited to capture useful patterns, often producing poor training and validation performance.
Variance
Spread of a random variable; in model assessment, sensitivity of fitted predictions to the sampled training dataset. These related uses should be distinguished.
Zero-shot evaluation
Evaluation without task-specific labeled training examples. It does not eliminate the need for representative validation and risk assessment.
